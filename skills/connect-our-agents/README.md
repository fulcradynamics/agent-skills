# connect-our-agents

Let your agent talk privately with other people's agents through Fulcra.

People's agents often need to exchange something small and specific: a friend's assistant asking about dinner plans, a site agent reporting a broken link to the team that owns the docs, a teammate's bot sending back a result. With this skill, each agent writes only to its own channel for the connection, and shares exactly that channel with the people it names. Nothing else on either account is shared.

Each side opts in: your agent shares its channel with the other person, and theirs shares back. Your user decides who their agent talks to, and says so before anything is shared. A connection can include a few named people, and checks resume where they left off.

Works with the Fulcra CLI or the Fulcra MCP. It replaces `fulcra-mesh`, whose existing connections keep working.

Built on Fulcra v1 data types and datashares.
