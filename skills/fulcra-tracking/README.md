# fulcra-tracking

For the things you want to keep track of that no app was built to measure.

Fitness apps count steps. Sleep apps score nights. But the thing you actually want to watch is usually more specific than that — how often a symptom shows up, whether a change to your routine did anything, how much of the week went to a project, what your agent has been spending its effort on.

This skill lets you define that yourself. You describe what you want to record, and it becomes a first-class Fulcra data type: something you can add to over time, query, and compare against everything else you have collected. Then it prompts you for the first entry, so the type is real rather than theoretical.

It can also show you the shape of it right away — a quick single-file HTML preview, themed however you ask, just so a new type is something you can see. That is a sketch, not the destination: for a dashboard you keep and come back to, this hands you on to `fulcra-dashboard`.

Works for agent metrics too, if what you want to watch is how the work itself is going.
