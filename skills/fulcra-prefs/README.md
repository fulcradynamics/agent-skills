# fulcra-prefs

Say it once. Every agent knows it after that.

"Use metric." "Never book me anything before 9am." "Stop explaining code I wrote." You tell one assistant, and then next week you tell another one, and then you tell the first one again because the session reset. Preferences that live inside a single chat die with it.

This skill keeps them somewhere else — in your Fulcra store, which belongs to you rather than to any one agent. Preferences are picked up at the start of a session, so an agent starts already knowing how you work. And they are captured as you express them: when you say "from now on…", or correct something an agent did, that becomes a durable preference rather than a correction it forgets.

Any agent you have given access reads the same set. Change your mind once and it changes everywhere.
